
Demo Instructions (Quick)
------------------------
1. Host on GitHub Pages or local HTTPS server (service worker requires HTTPS for production).
2. Open the site in Chrome on Android for best results.
3. Click "Request Permission" and allow notifications.
4. To enable background push:
   - Run the push-server/example (see push-server/README).
   - Copy VAPID public key and use "Enable Background" button to subscribe (paste key when prompted).
   - Send a test push using the server's /send endpoint with the subscription stored on server.
5. Add a habit with a reminder time one minute in the future and keep the tab open to test in-tab alarms.
6. For background push test, send push from server with payload like:
   {
     "title":"Habit: Drink Water",
     "body":"Time to drink water!"
   }
